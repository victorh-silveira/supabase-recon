# Curso sênior

## Passos

1. Abrir `docs/courses/senior-appsec-path.md` e `docs/courses/README.md`
2. Seguir módulos 1–7 na ordem; em cada um, abrir docs/rules/skills citados
3. Enfatizar AS-IS vs NORTE (`docs/engineering-senior-profile.md`)
4. Apresentar personas em `docs/agents/` conforme o módulo
5. No módulo 5, orientar comandos WSL: `make help`, `app-lint`, `app-test`, `app-security`
6. No módulo 6, skill `recon-ci-release`; no 7, skill `recon-surface-sync`
7. Não implementar itens NORTE a menos que o usuário peça explicitamente

`docs/engineering-senior-profile.md`, `docs/agents/README.md`, rule `recon-senior-profile`
